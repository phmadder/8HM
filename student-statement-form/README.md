# 학생 자기변론서 온라인 제출 (생교위 서식2)

학생이 휴대폰이나 PC로 **학생 자기변론서(서식2)**를 작성하고 **손글씨 서명**을 하면,
선생님 구글 드라이브 폴더에 자동으로 저장되는 웹앱임.

## 1. 동작 구조

```
학생 (휴대폰/PC 브라우저)
   │  ① 링크 접속 → 자기변론서 작성 → 손가락/마우스로 서명 → 제출
   ▼
Google Apps Script 웹앱 (선생님 계정으로 실행)
   │  ② 입력값 검사 (빠진 항목, 서명 유무)
   ▼
선생님 구글 드라이브 「생교위 학생 자기변론서 제출」 폴더
   ├─ 생교2026-008/                         ← 사건 번호별 하위 폴더 (링크에 ?case= 를 붙인 경우)
   │    ├─ 생교2026-008_자기변론서_홍길동_20261006-150312_서명.jpg   ← 서명 JPG
   │    └─ 생교2026-008_자기변론서_홍길동_20261006-150312          ← 작성된 자기변론서 (구글 문서, 서명 포함)
   └─ 제출 목록 (구글 시트)                   ← 1제출 = 1행, JPG·문서 링크 포함
```

| 용어 | 뜻 |
|---|---|
| Google Apps Script | 구글이 제공하는 무료 프로그램 실행 공간. 구글 드라이브·문서·시트를 코드로 다룰 수 있음 |
| 웹앱(Web App) | 주소(링크)만 있으면 브라우저로 여는 프로그램 |
| 배포(Deploy) | 만든 프로그램에 공개 주소를 붙여 다른 사람이 쓸 수 있게 하는 일 |
| 폴더 ID | 드라이브 폴더 주소 `https://drive.google.com/drive/folders/XXXX` 의 `XXXX` 부분 |

## 2. 파일 설명

| 파일 | 역할 |
|---|---|
| `Code.gs` | 서버 코드. 제출을 받아 서명 JPG·구글 문서·시트 기록을 드라이브에 저장함 |
| `Index.html` | 학생이 보는 작성 화면. 서식2 항목 + 서명 패드 |
| `appsscript.json` | 설정 파일(시간대 Asia/Seoul, 웹앱 실행 권한) |

서식 항목은 드라이브의 `교사사실확인서, 학생자기변론서, 목격자확인서.pdf`(서식2)와
`1_학생_자기변론서_*.docx`를 바탕으로 만들었음:
성명 · 학년/반 · 성별 / 누가(관련학생 모두) / 사안 기간(① 처음 있는 일 ○년 ○월 ○일 ○시경, ② ○개월간 ○번 정도) /
어디서(① 교실 ② 화장실 ③ 복도 ④ 기타: 학교 안( ) 학교 밖( )) / 무엇을·어떻게 / 왜 /
목격한 학생(① 같은 반 친구 ② 다른 반 친구) / 당시 상황을 자세하게 기술 / 작성일 / 작성 학생 (서명).

## 3. 설치 방법 (처음 한 번, 약 10분)

1. **script.google.com** 접속 → 생교위 서류를 보관하는 구글 계정으로 로그인 → **새 프로젝트**.
2. 프로젝트 이름을 `학생 자기변론서`로 바꿈.
3. 왼쪽 `Code.gs`의 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여넣음.
4. 왼쪽 **파일 +** → **HTML** → 이름을 `Index`로 입력(확장자 .html은 자동) → `Index.html` 내용 붙여넣기.
5. (선택) 왼쪽 **⚙ 프로젝트 설정** → "편집기에 appsscript.json 매니페스트 파일 표시" 체크 →
   `appsscript.json` 내용을 이 폴더의 것으로 교체. (시간대를 서울로 맞추는 용도. 안 해도 동작은 함)
6. (선택) `Code.gs` 맨 위 설정 수정:
   - `ROOT_FOLDER_ID`: 원하는 기존 폴더에 저장하려면 폴더 ID 입력. 비워 두면 내 드라이브에 `생교위 학생 자기변론서 제출` 폴더를 자동 생성함.
   - `ACCESS_CODE`: 아무나 제출하지 못하게 하려면 코드(예: `'0930'`) 입력. 학생은 이 코드를 넣어야 제출됨.
7. 위쪽 함수 선택 칸에서 **`setup`** 선택 → **▶ 실행** → 권한 승인 창에서 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → **허용**.
   (내가 만든 스크립트라서 구글이 경고를 띄우는 것임. 드라이브·문서·시트 접근 권한을 요청함)
8. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱** →
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (학생이 로그인 없이 제출) 또는 학교 Google Workspace라면 **도메인 내 모든 사용자**
   → **배포** → 나오는 **웹 앱 URL**을 복사함.

## 4. 사용 방법

- 학생에게 웹 앱 URL을 보냄 (카톡, QR 코드 등).
- 사건 번호별로 폴더를 나누려면 URL 끝에 `?case=사건번호`를 붙임.
  예) `https://script.google.com/macros/s/....../exec?case=2026-008`
  → 화면에 "사건 번호: 생교2026-008"이 표시되고, 파일이 `생교2026-008` 하위 폴더에 저장됨.
- 제출 결과는 드라이브 폴더와 `제출 목록` 시트에서 확인함.
- 서류 최종본이 HWPX여야 하면, 구글 문서를 **파일 → 다운로드 → .docx**로 받아 한글에서 열고, 서명 JPG를 붙여 쓰면 됨.

## 5. 코드를 고친 뒤

**배포 → 배포 관리 → ✏ 편집 → 버전: 새 버전 → 배포**를 해야 학생 화면에 반영됨. (URL은 그대로 유지됨)

## 6. 주의 사항

- 학생 진술은 민감한 개인정보임. URL을 사건 관련 학생에게만 보내고, 필요하면 `ACCESS_CODE`를 사용할 것.
- 제출 후에는 학생이 수정할 수 없음. 고칠 내용이 있으면 다시 제출하게 하고, 이전 파일은 선생님이 정리함.
- 서명 JPG는 흰 배경 + 검은 선으로 저장됨 (JPG는 투명 배경을 지원하지 않기 때문).
